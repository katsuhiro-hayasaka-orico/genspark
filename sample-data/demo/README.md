# デモ用サンプルCSV

このディレクトリのCSVは、アプリのスクリーンショット撮影・デモ用途で利用するためのサンプルです。

## 利用上の注意

1. すべて架空データです。実在の会社、契約、個人、社内システム、会計データを表すものではありません。
2. スクリーンショット撮影・デモ用途のために、部署、ベンダー、固定/変動、投資/運用、計画/見込/実績の差異が画面上で見えるように作成しています。
3. 実データ・個人情報・社内機密をこのディレクトリのCSVに混ぜないでください。
4. CSVを変更した場合は、`docs/03_data-import.md` とテストの整合性を確認してください。

## データ取込画面で選ぶファイル種別

| データ取込画面のファイル種別 | 対応CSVファイル名 | 用途 |
|---|---|---|
| 予実績管理データ | `budget-demo.csv` | 67期（2026年4月〜2027年3月）の計画・見込・実績を含むメインデータ |
| 新規案件マスタCSV | `new-project-master-demo.csv` | 新規案件の案件名、担当者、進捗、案件区分 |
| 新規案件月次金額CSV | `new-project-monthly-cost-demo.csv` | 新規案件の対象年月別の予算金額・見込金額 |
| OACIS実績 | `oacis-actual-demo.csv` | OACIS実績明細。`予実番号` 入りと空欄の行を含む |
| 減価償却シミュレーション | `depreciation-simulation-demo.csv` | 月次、半期、通期の償却シミュレーション |

## 推奨の取込順序

1. `budget-demo.csv` を「予実績管理データ」として取り込む。
2. 必要に応じて追加データとして、新規案件マスタCSV、新規案件月次金額CSV、OACIS実績、減価償却シミュレーションを取り込む。
3. ダッシュボード、ベンダー、明細、新規案件コスト、OACIS、減価償却の各画面で表示確認やスクリーンショット撮影を行う。
