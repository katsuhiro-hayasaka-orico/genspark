# ユーザーガイド

## アプリケーションの目的

予実績管理ダッシュボードは、統合CSVや追加CSVを取り込み、計画（plan）・見込み（forecast）・実績（actual）の差異、推移、カテゴリ別内訳、契約更新候補などをローカル環境で確認する可視化専用アプリです。READMEでは「完全ビジュアライゼーション専用（データ入力機能なし）」と説明されていますが、現行実装には差額理由・施策・契約属性を保存するAPIもあります。利用範囲の正式運用は要確認です。

## 初回起動・初期表示

1. 管理者または配布担当者の案内に従ってアプリを起動します。
   - ブラウザ利用時は `http://127.0.0.1:3000` を開きます。
   - Electron配布版では `.exe` を起動します。
2. 初期画面は「データ取込」です。
3. 初回起動時は「初回チュートリアル」ダイアログが表示される場合があります。
4. 左サイドバーには以下のメニューが表示されます。

| 区分 | 画面 |
|---|---|
| メインCSV | データ取込、全体サマリー、推移分析、カテゴリ別分析、アラート、ベンダー／契約更新、明細ドリルダウン |
| 追加CSV | 新規案件コスト、減価償却シミュレーション、OACIS実績 |
| ユーティリティ | 表示設定、使い方 |

## 基本的な操作手順

### 1. CSVを取り込む

1. 左メニューで「データ取込」を開きます。
2. 「ファイル種別」から取り込むCSV種別を選択します。
3. 「CSVファイルから取り込む」のドロップゾーンにCSVをドラッグ＆ドロップするか、ファイル選択欄からCSVを選びます。
4. 予実績管理データの場合は「読み込み結果サマリー（表示のみ）」と「エラーパネル（表示のみ）」を確認します。
5. 「CSVを取り込む」を押します。
6. 取込後、画面上部のステータスが「データ読込済」になり、サイドバー下部にファイル名と案件件数が表示されます。

### 2. 全体状況を確認する

1. 「全体サマリー」を開きます。
2. KPIカード、予算vs見込み/実績、報告用サマリー、差額ランキングを確認します。
3. 差額が大きい項目は、アラート画面または明細ドリルダウンで確認します。

### 3. 詳細を確認する

1. 「推移分析」で月次推移や変動ランキングを確認します。
2. 「カテゴリ別分析」で費目・システム・固定/変動・投資/運用などの観点別に確認します。
3. 「明細ドリルダウン」で管理番号、案件名、ベンダー名、部門名、担当者名などを検索して根拠データを確認します。

### 4. 表示を調整する

1. 画面右上のテーマ切替ボタンでライト/ダーク/ネオンのテーマを切り替えます。
2. 画面右上の `−`、`＋`、`100%` で表示倍率を調整します。
3. 「表示設定」でアラート閾値やKPI並び順を調整し、「反映」を押します。

## 画面構成

### データ取込

- ファイル種別選択、CSV選択、ドラッグ＆ドロップ、CSV取込、ブラウザ保存データクリア、取込状況を表示します。
- 選択できるファイル種別は、予実績管理データ、差額理由、新規案件マスタCSV、新規案件月次金額CSV、OACIS実績、減価償却シミュレーションです。
- Excelファイルの取込は現行画面では確認できません。CSVのみを選択する実装です。

### 全体サマリー

- 主要KPIと、予算・見込み・実績の概況を確認します。
- 金額単位は画面上の単位切替で「千円」「百万円」「億円」を切り替えられます。
- レポート出力ツールバーが表示されます。

### 推移分析

- 月次推移、前年差（YoY）、前月差（MoM）などの推移確認に使います。
- 表示期間や指標を切り替える操作があります。

### カテゴリ別分析

- 分析タブで集計軸を切り替え、構成比、差額、乖離率、ランキングを確認します。
- カテゴリ行から明細へのドリルダウンができる箇所があります。

### アラート

- 表示設定の閾値をもとに、差額・消化率・月次変動などの注意対象を表示します。
- アラート行から明細確認へ進む用途を想定しています。

### ベンダー／契約更新

- ベンダー別支出、契約更新・見直し一覧、契約属性とアラートを確認します。
- 契約日の正式な運用ルールは未確認です。仕様書でも一部未確認事項として扱われています。

### 明細ドリルダウン

- 「検索」欄で管理番号・案件名・ベンダー名・部門名・担当者名などを検索できます。
- 表示列はチェックボックスで切り替えできます。
- 行をクリックすると詳細ペインに月次データが表示されます。
- 「表示結果をCSV書き出し」で表示中の明細をCSVとしてダウンロードします。

### 新規案件コスト

- 新規案件マスタCSVと新規案件月次金額CSVをもとに、新規案件の予算・見込・進捗などを確認する画面です。
- 旧形式の新規案件予算見込CSVを扱うサーバ実装もありますが、画面の選択肢では2ファイル構成が優先されています。

### 減価償却シミュレーション

- 減価償却シミュレーションCSVを取り込み、期や償却展開区分名で絞り込んで確認します。
- 未取込の場合は、データ取込画面で対象CSVを取り込むよう案内が表示されます。

### OACIS実績

- OACIS実績CSVの実績合計額、明細件数、経費事象数、サプライヤ数、予実番号あり/なし金額などを確認します。
- 「予実番号未設定（要確認）明細」が表示されます。

### 表示設定

- 乖離率%、差額金額、前月比%、前年比%、重要KPI並び順を設定します。
- 「表示設定（データは変更しない）」と表示されており、元CSVの内容は変更しません。

### 使い方

- アプリ内の簡易ガイドです。
- 画面番号とメニュー順が同期しています。

## 入力・編集・保存の方法

### CSV取込による保存

CSVを取り込むと、サーバ側でローカル保存ファイルに永続化されます。保存先の詳細は[管理者ガイド](./admin-guide.md)を参照してください。

### 画面上の編集

現行の一般画面では、CSV由来データを直接編集する操作は中心機能ではありません。表示設定、明細表示列、テーマ、表示倍率、金額単位などの表示状態は画面操作で変更できます。

### ブラウザ保存データをクリア

1. 「データ取込」を開きます。
2. 「ブラウザ保存データをクリア」を押します。
3. 確認ダイアログで実行すると、サーバ側の保存データとブラウザの表示状態がクリアされます。

## フィルタ・検索・並び替え

### グローバルフィルター

データ取込、表示設定、使い方以外の主要画面では、上部にグローバルフィルターが表示されます。

| フィルター | 内容 |
|---|---|
| 集計軸 | 月次、四半期、通期 |
| 対象期(自) / 対象期(至) | 会計期範囲 |
| 対象月 | 年月 |
| 部門 | 全部門または部門別 |
| 観点 | 費目、システム、固定・変動、投資・運用 |
| 対象 | すべて、継続案件、新規案件、ベンダー別 |

### 明細検索

1. 「明細ドリルダウン」を開きます。
2. 検索欄に管理番号、案件名、ベンダー名、部門名、担当者名などを入力します。
3. 絞り込まれた行をクリックすると詳細ペインが更新されます。

### 並び替え

一部の画面仕様にはソートやランキング表示があります。列ヘッダクリックによる汎用テーブルソートが全画面に実装されているかは未確認です。

## インポート・エクスポート

### インポート

- 現行画面で確認できるインポートはCSVです。
- ファイル選択欄の `accept` は `.csv,text/csv` です。
- Excel、JSONのインポート操作は確認できません。

### エクスポート

| 操作 | 対象 | 注意 |
|---|---|---|
| PDF出力 | レポート出力ツールバーがある画面 | Electron環境で `window.desktop.exportPdf` がある場合に動作します。ブラウザのみでは利用できない場合があります。 |
| HTMLとして保存 | レポート出力ツールバーがある画面 | Electron環境で `window.desktop.exportHtml` がある場合に動作します。 |
| 表示結果をCSV書き出し | 明細ドリルダウン | 表示中の明細列を `displayed_detail.csv` としてダウンロードします。 |

## よく使う操作例

### 予実差額の原因を確認する

1. 「全体サマリー」で差額の大きいKPIやランキングを確認します。
2. 「アラート」で閾値超過の項目を確認します。
3. 対象行から「明細ドリルダウン」に進む、または明細検索で対象を絞り込みます。
4. 行をクリックして月次データとコメントを確認します。

### 新規案件の費用影響を確認する

1. 「データ取込」で「新規案件マスタCSV」と「新規案件月次金額CSV」を取り込みます。
2. 「新規案件コスト」を開きます。
3. KPI、月次、案件別の表示を確認します。
4. 必要に応じて金額単位を切り替えます。

### 表示を会議用に調整する

1. 右上のテーマ切替で見やすいテーマを選びます。
2. 表示倍率を `＋` / `−` で調整します。
3. 「表示設定」で閾値やKPI並び順を調整して「反映」を押します。

## 注意事項

- 本アプリはローカル専用の可視化アプリとして説明されています。
- 取り込むCSVの個人情報・機密情報の扱いは、組織のルールに従ってください。
- 追加CSVが未取込でも、予実績管理データをもとに各ページを表示します。
- 追加データの仕様が未確定の箇所は、空の本番風モックを作らず「データ未取込」または「追加データ未取込」として扱います。
