# 日常操作ガイド

## 画面構成

| 区分 | 画面 | 主な用途 |
|---|---|---|
| メインCSV | データ取込 | CSVの選択、取込、取込状況の確認、保存データクリア |
| メインCSV | 全体サマリー | KPIや差額ランキングで全体状況を確認 |
| メインCSV | 推移分析 | 月次推移や変動傾向を確認 |
| メインCSV | カテゴリ別分析 | 費目、システム、固定・変動、投資・運用などの観点で確認 |
| メインCSV | アラート | 差額や変動が大きい項目を確認 |
| メインCSV | ベンダー／契約更新 | ベンダー別支出や契約更新候補を確認 |
| メインCSV | 明細ドリルダウン | 管理番号、案件名、ベンダー名などで明細を検索 |
| 追加CSV | 新規案件コスト | 新規案件の費用状況を確認 |
| 追加CSV | 減価償却シミュレーション | 減価償却シミュレーションCSVの内容を確認 |
| 追加CSV | OACIS実績 | OACIS実績CSVの集計結果を確認 |
| 共通 | 表示設定 | 表示倍率、テーマ、アラートしきい値、KPI並び順を変更 |
| 共通 | 使い方 | アプリ内の簡易ガイドを確認 |

## 画面上部の操作

| 項目 | 内容 |
|---|---|
| ページ名 | 現在開いている画面名です。 |
| データ状態 | 「データなし」または「データ読込済」が表示されます。 |
| 設定ボタン | 「表示設定」画面を開きます。 |
| テーマ切替 | ライト/ダーク/ネオンを切り替えます。 |
| 表示倍率 | `−`、`＋`、`100%` で画面表示を調整します。 |
| グローバルフィルター | 対象期、対象月、部門、観点などを切り替えます。表示される画面で利用できます。 |

## 日常利用の基本手順

### 1. 全体状況を確認する

1. 「データ取込」でCSVを取り込みます。
2. 「全体サマリー」を開きます。
3. KPIカードと差額ランキングを確認します。
4. 気になる項目があれば「アラート」または「明細ドリルダウン」で詳細を確認します。

### 2. 推移を確認する

1. 「推移分析」を開きます。
2. 画面上部のフィルターで対象期や対象月を選びます。
3. 推移グラフやランキングを確認します。
4. 急に増減している月があれば、対象月で絞り込んで明細を確認します。

### 3. カテゴリ別に確認する

1. 「カテゴリ別分析」を開きます。
2. 分析したい観点やタブを選びます。
3. 構成比、差額、乖離率を確認します。
4. 必要に応じて明細へ移動し、根拠となる行を確認します。

### 4. アラートを確認する

1. 「アラート」を開きます。
2. 差額、消化率、月次変動などの注意対象を確認します。
3. 対象行から明細確認へ進める場合は、明細で根拠を確認します。

### 5. 明細を検索する

1. 「明細ドリルダウン」を開きます。
2. 「検索」欄に管理番号、案件名、ベンダー名、部門名、担当者名などを入力します。
3. 必要な表示列にチェックを入れます。
4. 行をクリックすると、詳細ペインに月次データが表示されます。
5. 必要に応じて「表示結果をCSV書き出し」を押します。

## フィルタの使い方

主要な分析画面では、画面上部にグローバルフィルターが表示されます。

| フィルター | 使い方 |
|---|---|
| 集計軸 | 月次、四半期、通期を切り替えます。 |
| 対象期(自) / 対象期(至) | 確認したい会計期の範囲を選びます。 |
| 対象月 | 特定の年月に絞り込みます。 |
| 部門 | 全部門または特定部門に絞り込みます。 |
| 観点 | 費目、システム、固定・変動、投資・運用を切り替えます。 |
| 対象 | すべて、継続案件、新規案件、ベンダー別などを選びます。 |

フィルターを変更すると、表示中の画面が再描画されます。

## 保存・編集・削除に関する操作

### 保存

CSVを取り込むと、取り込んだ内容はアプリ側に保存され、再表示に利用されます。保存場所や保存期間などの運用詳細は、この一般利用者向けマニュアルでは扱いません。

### 編集

現行画面では、取り込んだCSVの元ファイルを直接編集する操作は確認できません。表示設定、表示列、テーマ、表示倍率、金額単位など、画面表示に関する設定は変更できます。

### 削除・クリア

「データ取込」画面の「ブラウザ保存データをクリア」を押すと、取り込み済みデータや一部の表示状態をクリアします。実行前に、必要な出力や確認が終わっていることを確認してください。

## よく使う操作例

### 報告前に差額の大きい項目を確認する

1. 「全体サマリー」を開き、差額ランキングを確認します。
2. 「アラート」を開き、注意対象を確認します。
3. 「明細ドリルダウン」で該当する管理番号や案件名を検索します。
4. 行をクリックし、月次データを確認します。

### 会議用に画面を見やすくする

1. 画面右上のテーマ切替で見やすいテーマを選びます。
2. 表示倍率を `＋` / `−` で調整します。
3. 必要であれば「表示設定」でしきい値やKPI並び順を調整し、「反映」を押します。

## 注意事項

- 画面に表示される金額や件数は、取り込んだCSVに依存します。
- 追加CSVが未取込の場合、対象画面や一部項目が「データ未取込」と表示される場合があります。
- 並び替え操作は画面によって表示形式が異なります。列ヘッダークリックによる汎用的な並び替えが全画面で使えるかは未確認です。
