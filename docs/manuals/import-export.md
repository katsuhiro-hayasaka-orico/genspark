# 取込・出力ガイド

このページでは、CSV取込、取込時の確認、PDF/HTML/CSV/AI分析用プロンプト出力の手順を説明します。

## 取込できるファイル

- 現行画面で確認できる取込形式はCSVです。
- ファイル選択欄は `.csv` または `text/csv` を対象にしています。
- ExcelファイルやJSONファイルを直接取り込む操作は確認できません。
- UTF-8形式のCSV利用を推奨します。
- 先頭にBOMが付いたUTF-8 CSVは、取り込み時に処理されます。
- Shift_JISなど、UTF-8以外の文字コードでの正式対応は要確認です。

## 取込できるファイル種別

「データ取込」画面では、次のファイル種別を選択できます。

| ファイル種別 | 主な利用画面 | 補足 |
|---|---|---|
| 予実績管理データ | 全体サマリー、推移分析、カテゴリ別分析、アラート、ベンダー／契約更新、明細ドリルダウン | 主要画面を利用するためのメインCSVです。 |
| 差額理由 | 明細、差額理由に関する表示がある画面 | 管理番号などをキーに差額理由を補足します。 |
| 新規案件マスタCSV | 新規案件コスト | 新規案件月次金額CSVとあわせて利用します。 |
| 新規案件月次金額CSV | 新規案件コスト | 新規案件マスタCSVとあわせて利用します。 |
| 減価償却シミュレーション | 減価償却シミュレーション | 指定レイアウトのロング形式CSVを専用画面で集計します。 |
| OACIS実績 | OACIS実績 | 経費事象、サプライヤ、予実番号などを集計します。 |

デモ操作やスクリーンショット撮影では、リポジトリの `sample-data/demo/` にあるサンプルCSVを利用できます。サンプルCSVを使う場合は、次の対応表を目安に「ファイル種別」とファイル名を一致させてください。

| ファイル種別 | サンプルCSVファイル名 |
|---|---|
| 予実績管理データ | budget-demo.csv |
| 新規案件マスタCSV | new-project-master-demo.csv |
| 新規案件月次金額CSV | new-project-monthly-cost-demo.csv |
| OACIS実績 | oacis-actual-demo.csv |
| 減価償却シミュレーション | depreciation-simulation-demo.csv |

## 必須項目について

CSVには、画面表示に必要な列が含まれている必要があります。利用者向けマニュアルでは詳細な列定義は扱いません。配布されたテンプレートまたは所定の形式に従ってください。

列が不足している、列名が異なる、数値が読み取れないなどの場合は、取込前後にエラーや警告が表示されることがあります。

## CSVを取り込む手順

1. 左メニューの「データ取込」をクリックします。
2. 「ファイル種別」をクリックし、取り込むCSVの種類を選択します。
3. CSVファイルを「ドラッグ＆ドロップ」します。ファイル選択欄から選んでもかまいません。
4. 予実績管理データの場合は、「読み込み結果サマリー（表示のみ）」を確認します。
5. 「エラーパネル（表示のみ）」を確認します。
6. 問題がなければ「CSVを取り込む」をクリックします。
7. 大きいCSVでは、アップロード進捗が表示される場合があります。完了まで待ちます。
8. 取込が完了したら、画面上部が「データ読込済」になっていること、または対象の追加CSV画面へ自動遷移したことを確認します。
9. 「取込状況」で対象のファイル種別が取込済みになっていることを確認します。

## 取込時に画面で確認する内容

### 予実績管理データの場合

| 表示 | 確認すること |
|---|---|
| 取込ファイル名 | 選択したCSVが正しいか確認します。 |
| 読み込み件数 | 想定した件数と大きく違わないか確認します。 |
| 対象期間 | 想定した年月範囲か確認します。 |
| 欠損の多い列 | 重要な列が空欄になっていないか確認します。 |
| 数値列への文字混入候補 | 金額列などに文字が混じっていないか確認します。 |
| 追加分類列の検出 | `分類_XXX` などの列がカテゴリ別分析の分類軸として検出されたか確認します。 |

### 追加CSVの場合

追加CSVでは、選択したファイル種別に応じたプレビュー説明が表示されます。新規案件関連CSVは管理番号を結合キーとして利用します。減価償却シミュレーションCSVは、区分、償却展開区分、償却展開区分名、期間種別、期、月、金額を含むロング形式を前提に専用ビューで集計します。

## 取込時の注意点

- ファイル種別とCSVの内容を一致させてください。
- Excelファイルをそのまま選択しても、現行画面ではCSVとして取り込めません。
- ファイルの列名や形式は、配布されたCSVの形式に合わせてください。
- 追加CSVが未取込でも、予実績管理データをもとに主要画面を表示できます。
- 追加CSVが必要な画面では、対象データがない場合に未取込の案内が表示されます。
- 新規案件コストは「新規案件マスタCSV」と「新規案件月次金額CSV」の両方を取り込むと分析しやすくなります。

## 取込エラー時の確認方法

1. 「エラーパネル（表示のみ）」の内容を確認します。
2. 選択した「ファイル種別」が正しいか確認します。
3. CSVの列名が所定の形式と一致しているか確認します。
4. 金額や年月などに、想定外の文字が入っていないか確認します。
5. 空のCSVや別の資料を選んでいないか確認します。
6. 解決しない場合は、表示されたメッセージ、ファイル種別、ファイル名、操作日時を控えて問い合わせてください。

## 出力できるファイル・情報

| 出力 | 操作場所 | 保存される内容 |
|---|---|---|
| PDF出力 | レポート出力エリアがある主要ダッシュボード画面 | 表示中のレポート画面、出力日時、適用条件 |
| HTMLとして保存 | PDF出力ボタン横のメニュー | 表示中のレポート画面を単体HTML化したもの |
| AI分析用プロンプト | 全体サマリー | 表示条件に基づくMarkdownプロンプトとJSONコンテキスト |
| 表示結果をCSV書き出し | 明細ドリルダウン | 検索・表示列を反映した明細CSV |

PDF出力とHTML保存はElectron配布版で利用するデスクトップ機能です。ブラウザだけで開いている場合は「Electron環境ではないためPDF/HTML出力できません」と表示され、保存できません。

## PDFを保存する手順

1. 出力したい画面を開きます。
2. 必要に応じてフィルター、金額単位、表示倍率を調整します。
3. 画面タイトル付近の「PDF出力」をクリックします。
4. 保存先とファイル名を選択します。
5. 保存されたPDFを開き、内容を確認します。

## HTMLとして保存する手順

1. 出力したい画面を開きます。
2. 必要に応じてフィルター、金額単位、表示倍率を調整します。
3. 「PDF出力」横の `▼` をクリックします。
4. 「HTMLとして保存」をクリックします。
5. 保存先とファイル名を選択します。
6. 保存されたHTMLを開き、内容を確認します。

## AI分析用プロンプトを保存・利用する手順

1. 「全体サマリー」を開きます。
2. 必要に応じてフィルター、金額単位、表示倍率を調整します。
3. 「AI分析用プロンプト」をクリックします。
4. 分析粒度、差額上位件数、明細全件、担当者名の有無を確認します。
5. 「プロンプト生成」をクリックします。
6. 「プロンプトをコピー」でコピーするか、「Markdownを保存」「JSONを保存」でファイル保存します。
7. Copilot等に貼り付ける場合は、内容に機密情報が含まれていないか確認してから利用します。

## 明細CSVを書き出す手順

1. 「明細ドリルダウン」を開きます。
2. 検索欄にキーワードを入力します。
3. 必要な表示列にチェックを入れます。
4. 「表示結果をCSV書き出し」をクリックします。
5. `displayed_detail.csv` が保存されます。
6. 表計算ソフトなどで開き、必要に応じて集計や確認に利用します。

## 出力データを使うときの注意

- 出力前に、フィルター条件が意図した内容になっているか確認してください。
- PDF/HTMLには、出力時点の画面表示、出力日時、適用条件が含まれます。
- PDF/HTML出力時は、レポートヘッダーが自動的に展開されてから保存されます。
- 明細CSVは、画面に表示されている検索結果と表示列に基づきます。
- AI分析用プロンプトは、外部AIへ自動送信されません。ただし、利用者がコピーして外部サービスへ貼り付ける場合は、所属組織の情報管理ルールに従ってください。
- 出力ファイルに機密情報が含まれる場合があります。共有範囲や保存先は所属組織のルールに従ってください。
