# 取込・出力ガイド

## 取込できるファイル

現行画面で確認できる取込形式はCSVです。ファイル選択欄では `.csv` または `text/csv` が対象です。

| 形式 | 現行画面での扱い |
|---|---|
| CSV | 取込できます。 |
| Excel | 取込操作は確認できません。 |
| JSON | 取込操作は確認できません。 |

文字コードの正式な指定は画面上では確認できません。文字化けや列名の認識エラーがある場合は、CSVの保存形式を確認してください。

## CSVを取り込む

1. 左メニューで「データ取込」を開きます。
2. 「ファイル種別」を選びます。
3. CSVファイルをドロップゾーンにドラッグ＆ドロップするか、ファイル選択欄から選びます。
4. 表示されたプレビューやエラーパネルを確認します。
5. 「CSVを取り込む」を押します。
6. 取込後、画面上部の状態が「データ読込済」になるか確認します。

## ファイル種別の選び方

| ファイル種別 | 主な用途 |
|---|---|
| 予実績管理データ | 主要な分析画面で利用します。通常は最初に取り込みます。 |
| 差額理由 | 差額理由に関する表示で利用します。 |
| 新規案件マスタCSV | 新規案件コスト画面で利用します。 |
| 新規案件月次金額CSV | 新規案件コスト画面で利用します。 |
| OACIS実績 | OACIS実績画面で利用します。 |
| 減価償却シミュレーション | 減価償却シミュレーション画面で利用します。 |

ファイル種別とCSVの内容が一致していない場合、正しく取り込めないことがあります。

## 取込エラー時の確認方法

1. 「エラーパネル（表示のみ）」に表示される内容を確認します。
2. ファイル種別が正しいか確認します。
3. CSVの列名や区切り文字が、配布された形式と一致しているか確認します。
4. 空のファイルや、想定と異なるファイルを選んでいないか確認します。
5. 解決しない場合は、画面に表示されたメッセージ、ファイル種別、取込日時を控えて問い合わせてください。

## 出力できるファイル

| 出力 | 操作場所 | 内容 |
|---|---|---|
| PDF出力 | レポート出力ツールバーがある画面 | 表示中の画面をPDFとして保存します。 |
| HTMLとして保存 | レポート出力ツールバーがある画面 | 表示中の画面をHTMLとして保存します。 |
| 表示結果をCSV書き出し | 明細ドリルダウン | 表示中の明細をCSVとして保存します。 |

PDF出力とHTML保存は、配布版アプリで利用できる想定です。ブラウザだけで開いている場合に利用できるかは未確認です。

## 明細CSVを書き出す

1. 「明細ドリルダウン」を開きます。
2. 検索欄や表示列を調整します。
3. 「表示結果をCSV書き出し」を押します。
4. `displayed_detail.csv` として保存されます。
5. 保存したCSVを表計算ソフトなどで開いて確認します。

## 出力ファイルの利用方法

- PDFは会議資料や確認用資料として利用できます。
- HTMLは、画面の見た目に近い形式で保存したい場合に利用します。
- 明細CSVは、表示中の行をさらに集計・確認したい場合に利用します。

出力ファイルの共有範囲や保存先は、所属組織のルールに従ってください。
