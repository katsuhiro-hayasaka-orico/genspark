# トラブルシューティング

## 起動できない

### 症状

アプリを起動しても画面が開かない、またはエラーメッセージが表示されます。

### 考えられる原因

- 起動方法やURLが誤っている。
- すでに同じアプリが起動している。
- 利用環境でアプリの起動が制限されている。

### 対処方法

1. 配布された実行ファイル、または案内されたURLが正しいか確認します。
2. すでに起動している画面があれば、一度閉じてから再度起動します。
3. 端末を再起動してから、もう一度起動します。
4. エラーメッセージが表示される場合は、内容を控えます。

### それでも解決しない場合

利用している端末、起動方法、表示されたメッセージ、発生時刻を担当者に共有してください。

## 画面が表示されない

### 症状

画面が真っ白になる、読み込み中のまま進まない、またはメニューが表示されません。

### 考えられる原因

- アプリの読み込みが完了していない。
- ブラウザで開いているURLが誤っている。
- 一時的に画面表示が崩れている。

### 対処方法

1. 画面を再読み込みします。
2. ブラウザで開いている場合は、案内されたURLと一致しているか確認します。
3. アプリを閉じて再起動します。
4. 画面幅が極端に狭い場合は、ウィンドウを広げます。

### それでも解決しない場合

画面の状態、利用しているブラウザまたは配布版アプリ、発生した操作を担当者に共有してください。

## データを読み込めない

### 症状

CSVを選択しても取り込めない、エラーパネルに警告が表示される、または取込後も「データなし」のままです。

### 考えられる原因

- CSVではないファイルを選択している。
- 「ファイル種別」とCSVの内容が一致していない。
- 必要な列が不足している、または列名が異なる。
- 金額や年月などに読み取れない値が含まれている。

### 対処方法

1. ファイルの拡張子が `.csv` であることを確認します。
2. 「ファイル種別」がCSVの内容と一致しているか確認します。
3. 「エラーパネル（表示のみ）」の内容を確認します。
4. 配布されたCSV形式と列名が一致しているか確認します。
5. 大きいCSVの場合は、進捗表示が完了するまで待ちます。

### それでも解決しない場合

ファイル種別、ファイル名、画面に表示されたメッセージ、操作日時を担当者に共有してください。

## 入力内容が保存されない

### 症状

取り込んだデータや表示設定が、再起動後に残っていないように見えます。

### 考えられる原因

- 「ブラウザ保存データをクリア」を実行した。
- 利用環境の制限により保存領域が利用できない。
- 別の環境や別のブラウザで開いている。

### 対処方法

1. 取込後に画面上部が「データ読込済」になっているか確認します。
2. 「ブラウザ保存データをクリア」を実行していないか確認します。
3. 同じ端末、同じ起動方法で再度開いているか確認します。
4. 表示設定を変更した場合は、「反映」をクリックしたか確認します。

### それでも解決しない場合

どの操作を保存したいか、再起動後に何が消えたか、利用環境を担当者に共有してください。

## 表示が崩れる

### 症状

文字や表が見切れる、グラフが見づらい、メニューが操作しづらい状態です。

### 考えられる原因

- 表示倍率が大きすぎる、または小さすぎる。
- ブラウザ側の拡大率が変更されている。
- 画面幅が狭い。
- テーマと投影環境の相性が悪い。

### 対処方法

1. 画面右上の `100%` をクリックします。
2. 必要に応じて `−` または `＋` で表示倍率を調整します。
3. テーマ切替ボタンでライト/ダーク/ネオンを切り替えます。
4. ウィンドウを広げます。
5. ブラウザで開いている場合は、ブラウザ側の拡大率も確認します。

### それでも解決しない場合

表示が崩れている画面名、利用している表示倍率、可能であれば画面キャプチャを担当者に共有してください。

## エクスポートできない

### 症状

「PDF出力」「HTMLとして保存」「表示結果をCSV書き出し」を押しても保存できません。

### 考えられる原因

- 出力に対応していない画面を開いている。
- 保存先に書き込み権限がない。
- ブラウザだけで開いており、PDF/HTML出力が利用できない。
- ダウンロードがブラウザや端末で制限されている。

### 対処方法

1. レポート出力ツールバーが表示されている画面か確認します。
2. PDF/HTMLの場合は、配布版アプリで実行しているか確認します。
3. 保存先を変更して再度保存します。
4. 明細CSVの場合は、「明細ドリルダウン」で検索結果が表示されているか確認します。
5. ブラウザや端末のダウンロード制限を確認します。

### それでも解決しない場合

出力しようとした画面名、出力形式、表示されたメッセージ、保存先を担当者に共有してください。

## フィルタ結果が想定と違う

### 症状

表示される件数や金額が想定より少ない、多い、または明細が見つかりません。

### 考えられる原因

- 対象期、対象月、部門、観点、対象のフィルターが絞り込まれている。
- 他画面からの絞り込みが残っている。
- 検索欄に入力した文字が明細と一致していない。
- 追加CSVが未取込で、対象データがない。

### 対処方法

1. 画面上部のフィルター条件を確認します。
2. 部門を「全部門」に戻します。
3. 対象を「すべて」に戻します。
4. 明細ドリルダウンの検索欄を空にします。
5. 「絞り込み解除」が表示されている場合はクリックします。
6. 「データ取込」画面で取込状況を確認します。

### それでも解決しない場合

画面名、設定しているフィルター条件、検索語、期待していた結果を担当者に共有してください。

## 数値が合わない

### 症状

画面の金額や件数が、手元の資料や想定と一致しません。

### 考えられる原因

- フィルター条件が異なる。
- 金額単位が「千円」「百万円」「億円」などで切り替わっている。
- 対象月や対象期が異なる。
- 取り込んだCSVが想定と異なる。
- 追加CSVが未取込、または古いCSVを取り込んでいる。

### 対処方法

1. 画面上部のフィルター条件を確認します。
2. 金額単位を確認します。
3. サイドバー下部や取込状況で、取り込んだファイル名や状態を確認します。
4. 必要であれば、正しいCSVを再度取り込みます。
5. 明細ドリルダウンで対象データを検索し、根拠となる明細を確認します。

### それでも解決しない場合

比較している資料、画面名、フィルター条件、金額単位、取り込んだファイル名を担当者に共有してください。
