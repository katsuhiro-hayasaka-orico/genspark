# トラブルシューティング

## 起動できない

1. 配布された実行ファイルや案内されたURLが正しいか確認します。
2. 既に同じアプリを起動している場合は、一度終了してから再度起動します。
3. エラーメッセージが表示された場合は、メッセージ内容を控えて問い合わせてください。

## 画面が表示されない

1. アプリを再読み込みします。
2. ブラウザで開いている場合は、案内されたURLが正しいか確認します。
3. 画面が真っ白なままの場合は、アプリを終了して再起動します。
4. 解決しない場合は、利用している環境、起動手順、表示されたメッセージを控えて問い合わせてください。

## ファイルを読み込めない

1. ファイルがCSV形式か確認します。
2. 「ファイル種別」がCSVの内容と一致しているか確認します。
3. 「エラーパネル（表示のみ）」に表示された内容を確認します。
4. 空ファイルや、列名が異なるファイルを選んでいないか確認します。
5. 大きいファイルでは進捗表示が出る場合があります。完了まで待ってください。

## データが保存されない

1. 取込後に画面上部が「データ読込済」になっているか確認します。
2. 「ブラウザ保存データをクリア」を実行していないか確認します。
3. アプリを再起動し、取り込んだデータが表示されるか確認します。
4. 毎回データが消える場合は、利用環境の制限や配布設定が関係している可能性があります。状況を控えて問い合わせてください。

## 表示が崩れる

1. 画面右上の `100%` を押して表示倍率を戻します。
2. テーマを切り替えて表示を確認します。
3. 画面幅が狭い場合は、ウィンドウを広げるかサイドバーを折りたたみます。
4. ブラウザで開いている場合は、ブラウザの拡大率も確認します。

## エクスポートできない

### PDF/HTML出力

1. レポート出力ツールバーが表示されている画面か確認します。
2. 保存先に書き込みできるか確認します。
3. ブラウザだけで開いている場合、PDF/HTML出力が利用できない可能性があります。
4. 画面内に出力エラーが表示された場合は、そのメッセージを控えて問い合わせてください。

### 明細CSV出力

1. 「明細ドリルダウン」画面を開きます。
2. 検索条件を必要に応じて見直します。
3. 「表示結果をCSV書き出し」を押します。
4. ブラウザや端末のダウンロード制限を確認します。

## 検索しても明細が見つからない

1. 画面上部のフィルターで対象期、対象月、部門などが絞り込まれていないか確認します。
2. 明細ドリルダウンの検索欄を空にして再確認します。
3. 他画面からの絞り込みが残っている場合は「絞り込み解除」を押します。
4. CSVに対象の管理番号、案件名、ベンダー名などが含まれているか確認します。

## 追加データ画面が空になる

1. 対象の追加CSVを取り込んでいるか確認します。
2. 「データ取込」画面の「取込状況」を確認します。
3. 未取込の案内が出ている場合は、対象CSVを取り込んでから再度画面を開きます。
