# トラブルシューティング

## 起動できない

### Nodeサーバが起動しない

1. `npm install` が完了しているか確認します。
2. `npm run dev` または `npm start` を実行します。
3. ポート3000が使用中でないか確認します。必要に応じて `PORT` 環境変数で変更します。
4. 保存先ディレクトリに書き込み権限があるか確認します。

### Electron配布版でエラーが出る

READMEでは、`A JavaScript error occurred in the main process` や `Error: spawn ... ENOENT` が出る場合、旧ビルドの実行ファイルを使っている可能性があると説明されています。最新の配布物で再試行してください。

## ファイルを読み込めない

1. ファイル拡張子がCSVであることを確認します。
2. データ取込画面の「ファイル種別」がCSVの内容と一致しているか確認します。
3. 予実績管理データの場合は、プレビューの「エラーパネル（表示のみ）」を確認します。
4. 追加CSVの場合は、[CSV取込仕様](../03_data-import.md)の対象レイアウトと必須列を確認します。
5. 大きいCSVでは進捗表示が出る場合があります。完了まで待ってください。

## データが保存されない

1. サーバ側の保存先に書き込み権限があるか確認します。
2. 環境変数 `BUDGET_CSV_VIEWER_STORE_FILE` を指定している場合、指定パスが正しいか確認します。
3. 「ブラウザ保存データをクリア」または `POST /api/clear` を実行していないか確認します。
4. Electronを閉じた後に再起動し、ステータスが「データ読込済」になるか確認します。

## 表示が崩れる

1. ブラウザのズームではなく、アプリ右上の表示倍率を `100%` に戻します。
2. テーマを切り替えて表示を確認します。
3. 画面幅が狭い場合は、サイドバーを折りたたむか、十分な横幅で開きます。
4. キャッシュの影響が疑われる場合はブラウザを再読み込みします。

## エクスポートできない

### PDF/HTML出力

1. Electron版で実行しているか確認します。
2. 保存先に書き込み権限があるか確認します。
3. ブラウザで `http://127.0.0.1:3000` を直接開いている場合、PDF/HTML出力は利用できない可能性があります。
4. 出力エラーは画面内の出力ステータスを確認してください。

### 明細CSV出力

1. 「明細ドリルダウン」画面を開きます。
2. 検索や表示列を調整します。
3. 「表示結果をCSV書き出し」を押します。
4. ブラウザのダウンロード制限や保存先権限を確認します。

## 追加データ画面が空になる

1. 「データ取込」で対象の追加CSVを取り込んでいるか確認します。
2. 「取込状況」で対象ファイル種別が取込済みか確認します。
3. 減価償却シミュレーション画面では、未取込時に対象CSVの取り込み案内が表示されます。
4. OACIS実績画面では、OACIS実績CSVの行数や予実番号の有無を確認してください。

## 検索しても明細が見つからない

1. グローバルフィルターで対象期、対象月、部門、対象が絞り込まれていないか確認します。
2. 明細ドリルダウンの検索欄を空にします。
3. カテゴリ画面やアラート画面からのドリルダウン絞り込みが残っている場合は「絞り込み解除」を押します。
4. CSVに対象の管理番号・案件名・ベンダー名が存在するか確認します。

## ドキュメントサイトがビルドできない

1. Python環境を用意します。
2. `pip install -r requirements-docs.txt` を実行します。
3. `python -m mkdocs build --strict` を実行します。
4. navに存在しないMarkdownを指定していないか確認します。
