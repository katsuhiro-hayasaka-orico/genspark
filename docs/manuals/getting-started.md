# はじめに

## 初回起動

1. 配布担当者から案内された方法でアプリを起動します。
   - 配布版を利用する場合は、配布された実行ファイルを開きます。
   - ブラウザで利用する場合は、案内されたURLを開きます。
2. 画面が表示されたら、左側のメニューと画面上部の状態表示を確認します。
3. 初回起動時に「初回チュートリアル」ダイアログが表示された場合は、内容を確認して「始める」を押します。

## 初期画面

初期画面は「データ取込」です。画面上部には現在のページ名とデータ状態が表示されます。データ未取込の状態では、サイドバー下部に「未取込」と表示されます。

「データ取込」画面には、次の操作があります。

| 項目 | 内容 |
|---|---|
| ファイル種別 | 取り込むCSVの種類を選択します。 |
| ドラッグ＆ドロップ またはファイル選択 | CSVファイルを選択します。 |
| CSVを取り込む | 選択したCSVを取り込みます。ファイル選択前は押せません。 |
| ブラウザ保存データをクリア | 取り込み済みデータや一部の表示状態をクリアします。実行前に確認してください。 |
| 取込状況 | ファイル種別ごとの取込状態を確認します。 |

## 基本操作

### メニューを切り替える

1. 左側のメニューから見たい画面名を選びます。
2. データ未取込の状態では、主要な分析画面を開こうとしても「データ取込」画面に戻る場合があります。
3. 追加CSVだけで確認できる一部画面は、対象CSVが取り込まれていれば表示されます。

### 表示を見やすくする

- 画面右上のテーマ切替ボタンで、ライト/ダーク/ネオンの表示を切り替えます。
- 画面右上の `−`、`＋`、`100%` で表示倍率を調整します。
- 「表示設定」画面でも表示倍率とテーマを変更できます。

### 最初に確認すべきこと

1. 取り込むCSVの種類が「ファイル種別」と一致しているか確認します。
2. CSVを選択した後、表示されるプレビューやエラーパネルを確認します。
3. 取込後、画面上部が「データ読込済」になっているか確認します。
4. 「全体サマリー」を開き、主要な数値が表示されているか確認します。

## 最初に取り込むファイル

通常は「予実績管理データ」を先に取り込みます。追加CSVは、必要な画面を利用する場合に取り込みます。

| ファイル種別 | 利用する主な画面 |
|---|---|
| 予実績管理データ | 全体サマリー、推移分析、カテゴリ別分析、アラート、ベンダー／契約更新、明細ドリルダウン |
| 差額理由 | 差額理由を確認する表示がある画面 |
| 新規案件マスタCSV / 新規案件月次金額CSV | 新規案件コスト |
| OACIS実績 | OACIS実績 |
| 減価償却シミュレーション | 減価償却シミュレーション |

ファイルの正式な配布元や利用タイミングは、所属組織の運用ルールに従ってください。
