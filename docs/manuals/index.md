# 予実績管理ダッシュボード ユーザーマニュアル

このマニュアルは、予実績管理ダッシュボード（Budget CSV Viewer）を使ってCSVを取り込み、予算・見込み・実績の状況を確認する一般利用者向けの手順書です。

## マニュアルの目的

- 初めて利用する方が、起動後に何をすればよいか分かるようにする。
- CSVの取り込み、画面の見方、検索、出力などの日常操作を説明する。
- トラブル時に、利用者自身で確認できる範囲の対処方法をまとめる。

## 対象利用者

| 対象 | このマニュアルで扱うこと |
|---|---|
| 予実績データを確認する利用者 | CSV取込後の画面確認、フィルタ、検索、出力 |
| 会議・報告資料を準備する利用者 | KPI、推移、アラート、明細の確認 |
| 問い合わせ前に状況を整理したい利用者 | よくある質問、トラブル時の確認手順 |

このマニュアルには、内部仕様、開発者向け手順、詳細なデータ定義、システム運用設定は含めません。

## 基本的な利用の流れ

1. アプリを起動します。
2. 「データ取込」画面でファイル種別を選び、CSVを選択します。
3. プレビューやエラーパネルを確認し、「CSVを取り込む」を押します。
4. 「全体サマリー」で全体の状況を確認します。
5. 必要に応じて「推移分析」「カテゴリ別分析」「アラート」「明細ドリルダウン」で詳細を確認します。
6. 報告や共有が必要な場合は、画面の出力機能または明細CSV出力を利用します。

## 注意事項

- このアプリで確認できる内容は、取り込んだCSVの内容に基づきます。
- ExcelやJSONの取込は、現行画面では確認できません。
- 操作や業務ルールがこのマニュアルだけでは判断できない場合は、「要確認」として扱ってください。
