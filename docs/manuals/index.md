# 予実績管理ダッシュボード ユーザーマニュアル

このマニュアルは、予実績管理ダッシュボードを日常利用する方向けの操作ガイドです。CSVを取り込み、予算・見込み・実績の状況を確認し、必要な明細や出力を得るまでの流れを説明します。

## このマニュアルの対象者

| 対象者 | このマニュアルで分かること |
|---|---|
| はじめてアプリを使う方 | 起動後に最初に確認する画面、CSV取込の流れ |
| 予実績データを確認する方 | 全体サマリー、推移、カテゴリ、アラート、明細の見方 |
| 報告や確認資料を作る方 | PDF/HTML出力、明細CSV出力、表示倍率やテーマの調整 |
| 困ったときに自己確認したい方 | 取込エラー、表示崩れ、検索結果、出力失敗時の確認手順 |

このマニュアルでは、利用者が画面上で操作する内容だけを扱います。システムの内部構造、詳細な項目定義、運用設定、開発者向け手順は扱いません。

## このアプリでできること

- CSVを取り込み、予算・見込み・実績の状況を画面で確認できます。
- 全体のKPI、月次推移、カテゴリ別の内訳、アラート、ベンダー別の状況を確認できます。
- 明細ドリルダウンで、管理番号・案件名・ベンダー名・部門名・担当者名などを検索できます。
- 新規案件、減価償却シミュレーション、OACIS実績など、追加CSVに応じた画面を確認できます。
- 表示中の画面をPDFまたはHTMLとして保存できます。
- 明細ドリルダウンの表示結果をCSVとして書き出せます。
- テーマ、表示倍率、金額単位など、見やすさに関する表示を調整できます。

## 基本的な利用の流れ

1. アプリを起動します。
2. 「データ取込」画面を開きます。
3. 「ファイル種別」で取り込むCSVの種類を選択します。
4. CSVファイルを選択し、プレビューやエラーパネルを確認します。
5. 「CSVを取り込む」をクリックします。
6. 画面上部が「データ読込済」になったことを確認します。
7. 「全体サマリー」で全体の状況を確認します。
8. 必要に応じて「推移分析」「カテゴリ別分析」「アラート」「明細ドリルダウン」で詳しく確認します。
9. 必要な場合はPDF、HTML、明細CSVとして出力します。
