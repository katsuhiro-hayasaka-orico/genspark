この取扱説明書は、予実績管理ダッシュボード（Budget CSV Viewer）を利用・導入・運用するためのガイドです。現行の `server.js`、`public/static/app.js`、`public/index.html`、Electron設定、README、既存仕様書から確認できる範囲で作成しています。

## このマニュアルで分かること

- 初回起動後に表示される画面と基本的な操作の流れ。
- CSVファイルの取り込み、プレビュー、保存データクリアの操作。
- 主要画面の役割、フィルター、検索、出力操作。
- ローカル起動、Electron起動、Windows配布物作成、データ保存先。
- 現行実装から想定できるFAQとトラブル対処。
