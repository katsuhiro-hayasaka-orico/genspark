# 予実績管理ダッシュボード ドキュメント

このサイトは、Budget CSV Viewer（予実績管理ダッシュボード）の仕様書と取扱説明書をまとめて閲覧するためのドキュメントサイトです。

## ドキュメントの構成

| 区分 | 内容 | 主な読者 |
|---|---|---|
| [仕様書](./01_overview.md) | 実装と同期して管理する Docs as Code 仕様書 | 開発者、保守担当者、レビュー担当者 |
| [取扱説明書](./manuals/index.md) | 現行ソースコード・画面構成・README・既存仕様書から作成した利用者向け手順 | 利用者、導入・運用担当者 |

## MkDocs統合方針

既存仕様書はすでに `docs/` 配下で管理されているため、MkDocsの `docs_dir` も `docs/` とし、仕様書の原本移動は行いません。`adr/` は `docs_dir` の外にあるため、MkDocsで相対リンク切れを起こさないよう `docs/adr/` に同内容を配置しています。ADR原本を更新した場合は `docs/adr/` 側も同期してください。取扱説明書は `docs/manuals/` に追加し、仕様書と同一サイトのナビゲーションから参照できるようにします。

## 注意事項

- 取扱説明書は、現行ソースコードから確認できる範囲で記載しています。
- ソースコードや仕様書だけでは確定できない事項は「未確認」「要確認」「TODO」と明記しています。
- 生成物の `site/` と `dist/` は通常ブランチにコミットしません。
